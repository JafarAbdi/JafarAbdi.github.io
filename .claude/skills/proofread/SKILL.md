---
name: proofread
description: Check a post file for grammar and readability before publishing
---

Read the file passed as argument: $ARGUMENTS

Report only, don't edit.

Pass 1, correctness: spelling, grammar, punctuation. Quote each span, one-line fix, worst first.

Pass 2, reader flow: jargon used before it is introduced, sections out of intuitive order, logical jumps needing a bridge, redundant passages. Quote each span, why it trips a reader, fix.

End with one line: publishable as-is, or the single most important thing to fix.

No em-dashes in suggestions. No praise, no preamble, no summary.
